Step-by-Step Guide

1
Configure Settings

Go to the Settings tab and add your Phemex API key and secret. Enable testnet first to practice safely.

2
Expose Your Server

Use a service like ngrok to expose your local server: ngrok http 5000. Copy the HTTPS URL.

3
Create TradingView Alert

Open your chart, click "Add Alert", set your condition. In the "Webhook URL" field, paste your-ngrok-url/webhook.

4
Set Alert Message

In the alert's "Message" field, paste the JSON template above. Use TradingView placeholders like {% raw %}{{close}}{% endraw %}, {% raw %}{{ticker}}{% endraw %}, {% raw %}{{strategy.order.contracts}}{% endraw %}.

5
Test It

Click "Test Connection" in Settings to verify Phemex connectivity. Then trigger your alert and watch the Dashboard for results.
